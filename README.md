# PreSchool — Goldilocks Pre School

A modern, playful, premium kindergarten and preschool website for **Goldilocks Pre School**, Lake Town, Kolkata.

## 🌟 Highlights
- **Modern Aesthetic**: Warm pastel Montessori styling, rounded typography (Fredoka, Baloo 2, Nunito), floating organic illustrations, and polished Apple-inspired micro-interactions.
- **Direct WhatsApp Integration**: Visit booking and admission enquiry forms automatically validate input and dispatch pre-filled structured messages directly to WhatsApp (+91 89105 74735).
- **Multi-Page Architecture**:
  - **Home**: Dynamic hero, 3 learning pillars (Explore, Create, Grow), program cards, principal spotlight, interactive gallery preview, parent testimonials, and location map.
  - **About Us**: Our story, vision & mission, early childhood science, and child-proofed safety infrastructure.
  - **Programs**: Detailed milestones, student-teacher ratios, and daily schedules for Playgroup, Nursery, Kindergarten, and School Readiness.
  - **Activities**: Clay modeling & pottery, glass painting, yoga & mindfulness, zoo expeditions, and weekly rhythm calendars.
  - **Gallery**: Responsive masonry grid with category filters and keyboard-navigable full-screen lightbox modal.
  - **Contact**: Click-to-call (+91 89105 74735 / +91 98160 53287), email, embedded Google Map, and admission form.
- **Mobile First & Responsive**: Optimized touch navigation, floating WhatsApp quick action button, and zero horizontal overflow.
- **SEO Ready**: Schema.org Preschool JSON-LD structured data, Open Graph cards, sitemap.xml, and robots.txt.

## 🚀 Tech Stack
- **React 19**
- **Vite 6**
- **Tailwind CSS 3**
- **Lucide React**
- **Canvas Confetti**
